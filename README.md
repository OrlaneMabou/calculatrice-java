# Calculatrice (Java)

This was my very first personal project — a simple starting point to get comfortable with Java outside of university assignments. I built a console-based calculator that handles the 6 most common operations: addition, subtraction, multiplication, division, exponentiation, and square root. I added basic error handling for edge cases like division by zero and square roots of negative numbers. Nothing fancy, but it was a solid first step into writing clean, structured Java code on my own.

## Operations
-  Addition
-  Subtraction
-  Multiplication
-  Division
-  Exponentiation (xⁿ)
-  Square root

## How to run
```bash
cd src
javac Calculatrice.java
java Calculatrice
```
